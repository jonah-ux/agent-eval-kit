02 / run locally

Run the included demo.

The published v0.3.0 prerelease includes a one-fixture demo. It needs Python 3.11+ and no model account. For matrix-plan comparisons, see the README.

git clone --branch v0.3.0 --depth 1 https://github.com/jonah-ux/agent-eval-kit.git cd agent-eval-kit python3 -m venv .venv . .venv/bin/activate python3 -m pip install . python3 demos/demo.py
