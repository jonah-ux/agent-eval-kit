# Changelog

All notable changes to agent-eval-kit are documented here.

## [Unreleased]

## [0.1.0] - 2026-09-30

- Added a provider-neutral Python 3.11+ fixture runner.
- Added bounded command execution with `{task}` substitution and fresh task
  workspaces.
- Added expected exit-code, file, and JSON assertions.
- Added deterministic scorecards, JSONL lifecycle events, JUnit output, and
  configurable regular-expression redaction.
- Added synthetic passing and deliberately failing fixtures plus an installed demo.
